Entre 2023 y 2025 se difundieron varios marcos para estructurar prompts. Aquí tienes una selección práctica —no es una lista exhaustiva— con sus componentes habituales. Los acrónimos pueden variar un poco según la fuente:

| Marco | Componentes | Útil para |
|---|---|---|
| **CLEAR** (2023) | Conciso, lógico, explícito, adaptable y reflexivo | Revisar y mejorar prompts; también destaca documentar los cambios |
| **MPF** (2023) | Secciones como tarea, contexto, restricciones y ejemplos | Organizar prompts de forma legible y reutilizable en equipos o flujos de trabajo |
| **CO-STAR** | Contexto, objetivo, estilo, tono, audiencia y respuesta | Redacción donde importan el público y la voz |
| **CRAFT** | Contexto, rol, acción, formato y público objetivo | Contenido con formato y lector definidos |
| **RISEN** | Rol, instrucciones, pasos, objetivo final y restricciones | Tareas complejas o de varias etapas |
| **CRISPE** | Capacidad/rol, información, declaración, personalidad y experimento | Explorar enfoques o generar variaciones |
| **RTF** | Rol, tarea y formato | Pedidos sencillos y directos |
| **RACE** | Rol, acción, contexto y expectativa | Solicitudes profesionales de propósito general |

Por ejemplo, **CO-STAR** para una tarea de redacción podría quedar así: “Contexto: lanzamiento de una aplicación de finanzas personales. Objetivo: redactar una descripción para la página web. Estilo: claro y cercano. Tono: confiable, sin exageraciones. Audiencia: personas que recién empiezan a organizar sus gastos. Respuesta: 120 palabras, con un título y un párrafo”.

Como punto de partida, usa **RTF** para algo simple; **CO-STAR** si el tono y la audiencia son clave; y **RISEN** si necesitas ordenar una tarea compleja. Estos marcos son plantillas útiles, no estándares universales. <citation src="3"></citation><citation src="5"></citation>
